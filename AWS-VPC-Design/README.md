\# AWS Secure VPC Architecture



\## Project Overview



Designed a secure, scalable, and highly available three-tier AWS VPC architecture for Cloud Growth Limited.



\## Architecture Diagram



!\[AWS VPC Architecture](AWS-VPC-Architecture.png)



\## Infrastructure Components



\- AWS Region: us-east-2 (Ohio)

\- 1 VPC (10.0.0.0/16)

\- 2 Availability Zones

\- 6 Subnets (2 Public, 2 Application, 2 Database)

\- 1 Internet Gateway

\- 2 NAT Gateways

\- 4 Custom Route Tables

\- Application Load Balancer

\- Amazon EC2

\- Amazon RDS Multi-AZ

\- Security Groups and Network ACLs



\## Security and High Availability



\- Network segmentation and isolation

\- Private database subnets

\- Redundant NAT Gateways

\- Controlled outbound internet access

\- Defense-in-depth security

\- Multi-AZ architecture



\## Skills Demonstrated



\- AWS Cloud Networking

\- VPC Architecture Design

\- CIDR and Subnetting

\- Route Tables and Traffic Routing

\- Cloud Security Engineering

\- High Availability and Fault Tolerance
